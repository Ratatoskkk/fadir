# Keep the direct Yahoo source for the beta

The owner confirms that the written Yahoo permit covers the beta. The exact grant stays outside the public repository.

The beta will keep the current direct Yahoo integration. It will not add a provider seam before launch only for a possible future source change.

This choice saves early work but increases the cost of a later provider change. The team will replace the source if the permit changes or the source fails.

The market-data report records the available alternatives and the questions for each provider.
