# Launch with Turkey and add Tax Jurisdictions later

The open beta will target Turkey and use Turkish tax rules first. A later phase can add a country only after Turkey passes public beta acceptance.

A Tax Profile belongs to one User, Tax Jurisdiction, and tax year. All of the User's Portfolios can contribute to one Tax Estimate. A Portfolio can show its own contribution.

Each Tax Estimate will use the jurisdiction currency instead of the Portfolio Base Currency.

The first public release will keep the Turkey Tax Estimate. The beta proof must include an official source, a visible tax year, fixed calculation tests, and the current disclaimer.

A later production policy can add a complete official-source record for each tax year.
